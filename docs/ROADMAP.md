# Build Roadmap

## Foundation — now
Repository, TypeScript/Next.js web shell, design system, architecture docs, environment conventions.

## Core social
Accounts/authentication, profiles, follows/friends, posting, video upload/media pipeline, feed, comments, likes, shares, saves, search/discovery, notifications, Stories, report/block.

## Conversation
Messaging, Circles, The Porch, Receipts, Creator Studio.

## Live
Live broadcasting, guest queue, chat, moderation, camera controls, lenses/filters/effects, scheduled/replay/clip flows. Native mobile performance work is required here.

## Creator economy
Gifts, tips, subscriptions, paid Circles/ticketed digital events where enabled, wallet, payouts, financial controls. No marketplace/store/product sales.

## Owner HQ
Staff auth + MFA, RBAC, users/creators, moderation, appeals, Live safety, finance, analytics, support, audit logs, feature flags, system health.

## Scale + launch
Recommendation system, search tuning, analytics pipelines, abuse prevention, observability, backups/restore testing, load testing, privacy/legal flows, music licensing, app-store preparation, penetration testing and staged rollout.

A feature is not called "launched" merely because a screen exists. It must be implemented, integrated, tested and deployed.
